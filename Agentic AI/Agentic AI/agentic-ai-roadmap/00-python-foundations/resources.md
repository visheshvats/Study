# Phase 00: Resources

Here are curated resources to deepen your understanding of Python for modern AI development, particularly coming from a strongly-typed background like Java.

### Official Documentation
1. **[Python Official Type Hinting Docs](https://docs.python.org/3/library/typing.html)** - The definitive guide to Python's typing module (crucial for Java devs).
2. **[FastAPI Documentation](https://fastapi.tiangolo.com/)** - The official FastAPI docs. One of the best-written documentation sites in the Python ecosystem.
3. **[Pydantic Documentation](https://docs.pydantic.dev/latest/)** - The industry standard for data validation. Think of it as JSON schema validation on steroids.

### Articles & Tutorials
4. **[Real Python: Async IO in Python: A Complete Walkthrough](https://realpython.com/async-io-python/)** - A comprehensive guide to understanding the Event Loop and `async/await`, contrasting it with multithreading.
5. **[Python's Mutable Default Arguments: A "Gotcha"](https://docs.python-guide.org/writing/gotchas/#mutable-default-arguments)** - A vital read explaining the most common bug introduced by developers switching from Java to Python.

### Tools & Repositories
6. **[Ruff (Linter & Formatter)](https://github.com/astral-sh/ruff)** - An extremely fast Python linter written in Rust. It's the modern replacement for Flake8/Black and essential for production Python code.
