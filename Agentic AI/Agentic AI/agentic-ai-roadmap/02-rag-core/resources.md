# Phase 02: Resources

Curated resources to master Retrieval-Augmented Generation.

### Official Documentation
1. **[LangChain Document Loaders](https://python.langchain.com/v0.2/docs/how_to/#document-loaders)** - The official guide for connecting to PDFs, CSVs, AWS S3, Google Drive, etc.
2. **[LangChain LCEL Cheat Sheet](https://python.langchain.com/v0.2/docs/how_to/lcel_cheatsheet/)** - Highly recommended! LCEL syntax can be confusing at first; this cheat sheet is the best way to understand how the `|` pipe operator routes data.
3. **[Chroma DB Documentation](https://docs.trychroma.com/getting-started)** - The easiest vector database to run locally in Python. Great for prototyping.

### Articles & Tutorials
4. **[Pinecone: What is a Vector Database?](https://www.pinecone.io/learn/vector-database/)** - An excellent, visual explanation of how embeddings work, what vector dimensions are, and how cosine similarity is calculated.
5. **[Advanced RAG Techniques (FreeCodeCamp)](https://www.freecodecamp.org/news/mastering-rag-from-scratch/)** - A deep dive into moving beyond basic Top-K retrieval, touching on chunking strategies and semantic search.

### Tools & Repositories
6. **[LangChain (GitHub)](https://github.com/langchain-ai/langchain)** - The core framework repository. Exploring the source code for `RecursiveCharacterTextSplitter` is a great way for Java devs to see production Python OOP.
